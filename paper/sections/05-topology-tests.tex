\section{What would turn the local picture into an explanation?}
\label{sec:mechanism}

The strongest remaining question is causal: does a change in reinjection
predict which periodic windows connect? A branch count is an observation.
To explain the spirals, it must be linked to geometry that can be followed
across parameter space and tested at points not used to define it.

The next local target is the unstable lobe associated with the two/three-branch
change. We need a signed, convergent measurement of how stable and unstable
manifolds meet, or of which symbolic trajectories become accessible. Its
zero or discontinuity should predict the observed branch change. The same
measurement must survive changes of section and numerical resolution. A
finite PIM sample that misses a lobe cannot by itself prove the lobe absent
from the infinite-time invariant set.

The second target is Jones's finite symbolic claim. Symbolic dynamics replaces
each visit to a return-map branch by a letter or digit, making an orbit into
a cyclic word. The original Figure 6 has been transcribed into 23 words
through period seven and their proposed connections. An independently
constructed alphabet is partly qualified, but the first exact-coordinate
landmark test does not reproduce the expected word. The source coordinates
are approximate and the partition is incomplete, so this is a failed
reproduction at those coordinates rather than a refutation of every
proposed connection.

Finite agreement with logistic-map ordering must be tested directly.
Related finite ordering was already observed in experimental flows
\citep{lefranc1994combining}, and two-dimensional return maps can exhibit
high-period orderings unavailable to one-dimensional unimodal maps
\citep{holmes1984bifurcation}. The comparison should therefore enumerate
orbit words, permutations, and stability through the original finite range,
then report the first mismatch or a declared search limit.
The finite-pattern literature and topological-template framework provide
distinct reference objects \citep{metropolis1973finite,gilmore1998topological};
neither can be inferred from a visually similar scalar plot.

The intended visual result is an unfolded spiral: parameter position,
branch geometry, orbit points, and symbolic words shown together, with
each proposed connection traceable to computed data. The detailed source
transcription and unsuccessful tests remain in
Appendix~\ref{supp:symbolic}. That figure, backed by held-out predictions,
would answer the original explanatory question more directly than another
doubling or another short continuation step.
