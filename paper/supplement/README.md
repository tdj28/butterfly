# Supplementary visual material

- rossler-multib-atlas.gif is Supplemental Movie S1. Its eleven frames animate
  the same EXP-021 \(b=0.10,\ldots,0.30\) recurrence atlases shown in
  manuscript Figure 1. It is a metadata-stripped, frame-optimized publication
  copy of artifacts/EXP-021/EXP-021-multi-b-ac-atlas.gif (source SHA-256
  399adfc9c27fa25a87e37e62667cc8284d5c7ebad8d5d86cd99db82a28618d98).

As with Figure 1, the animation shows finite-time classifications. It
visualizes smooth deformation of the observed parameter-plane structure; it
does not continue invariant bifurcation curves through three parameters.
