# EXP-221 exposes a coarse-step primitive-root jump

The qualified returning-arm child passes at its seed but the first coarse
event step selects a different primitive `14/16` root with period ratio
`2.01045` and multiplier modulus `5588.9`. It is neither the stable child nor a
doubled parent.

EXP-222 freezes a 16-substep bridge over exactly that interval using the
closest independently qualified child to the event. All stability,
primitivity, section-identity, period-ratio, and cross-solver gates remain
unchanged.
