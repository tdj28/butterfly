# EXP-502 local pre-outcome design audit

This is a local agent audit, not independent-team replication or a paid Pro
review. No EXP-502 target trajectories existed during this design review.

- **Scientific target:** test one local two-contact explanation, not pronounce
  Jones's entire symbolic mechanism true/false from one orbit. A zero projected
  residual cannot license a full-state contact or a C/D identification.
- **Selection disclosure:** the cycle index and anchor come from EXP-497/501
  outcomes. All eight stencil points, 256 correlated variants, and both scales
  are required; no favorable subset, index rotation or retry is allowed.
- **Failure preservation:** primitive-cycle and representation failures stop a
  proposal, not the remaining stencil points. Exceptions consume the attempt
  and retain all unfinished slots. Previous 26 ledger entries remain intact.
- **Counts/retention defect found before outcomes:** the old census helper
  integrates a short guard before its main trajectory but returns only the
  latter mesh. A successor-only wrapper counts before each call and archives
  that guard, with a separate endpoint-continuity audit. Old reported archive
  counts are not silently corrected or presented as exhaustive call counts.
- **Method controls:** analytic folds/nonfolds/degenerate projections, single
  versus doubled circle traversal, decimal grazing/variation and complete
  polynomial census, synthetic joint Jacobians and failure cases. No new
  target trajectory is used to tune a threshold.
- **Reproducibility:** complete imported source closure plus authenticated
  compact inputs, fresh isolated copied-source startup, clean public source
  check before execution, all target meshes/coefficient streams, and a
  hash-first raw audit before scientific interpretation. The scalar matrix
  inversion provides a different arithmetic check but shares measured inputs.
- **Boundaries:** two-method agreement is not an error enclosure. Prefix
  polynomial root completeness does not prove exact-flow root completeness.
  Legacy cycle/fold audits share classification helpers. The inherited fold
  control producer preserves reports but not its full control meshes.
- **Resources:** bounded local CPU run, no API keys, no paid review, no cloud
  rentals, no new raw uploads or cleanup. Initial/reserve/cumulative caps apply
  before consuming the attempt. Preparation and tests are not research results.

Validation receipts and the public source commit will be recorded in the
update log before interpretation. Any pre-outcome defects discovered by tests
are repaired openly before freezing; a post-outcome change requires a successor.

The strengthened isolated-startup test initially failed because macOS exposes
the temporary directory through `/var` while resolved module paths use
`/private/var`. The copied root is now normalized before checking ancestry;
the ancestry assertion remains mandatory. The failed 14-pass/1-fail focused
receipt is retained as `artifacts/EXP-502/preflight-focused-02.xml`. No target
attempt was consumed and no scientific thresholds were changed.
