# EXP-516: look for coverage across every saved return ordinal

## Post-result diagnostic, not a new confirmation

EXP-512's complete results and EXP-514/515's grazing and precision outcomes
were known before this analysis was designed. EXP-510 transports the original
upstream curve's x/z anchor unchanged while changing parameters and its y
section offset. It also fixes the requested return ordinal. EXP-486 originally
obtained those anchors from actual histories at the old parameters. Neither
fact alone proves that a later curve has lost the physical fold.

Grazing changes event counts. Before constructing new curves, test the cheaper
alternative: is the depth-four reference approached on a different retained
return of either old depth-eight upstream curve? This is an outcome-informed
saved-data screen. It cannot replace any old endpoint, certify an unsampled
interval, qualify a fold or verify a Jones symbolic chain.

## Complete comparison and unchanged safeguards

Authenticate the public EXP-512 receipt, the EXP-511 plan containing all four
depth-four references, the original EXP-486 receipt, and the EXP-510 transport
source. Use both directions, all twenty nodes per direction, both solvers,
and **every consecutive accepted event pair** in each saved reconstructed
extremum-aware census. Do not limit the screen to eighth-to-ninth returns.
Do not call unequal ordinals the same event sheet. Report the last event
without a successor as right-censored. Unequal available ordinals stay missing,
not silently paired or interpolated. Horizons differ for the seven previously
extended nodes; this limits coverage comparisons and is reported explicitly.

Recompute event-corrected tangents from the saved full state and raw variation.
Validate direction, gate, residual and normalized angle against the Rössler
field. Retain the original gain >= 1e-4, normalized input x component >= .001,
angle >= 1e-7, plane residual <= 1e-8, paired scaled-state <= 1e-6 and time
<= 1e-7 gates. Paired unit-tangent and scalar-slope agreement use the original
EXP-511 tolerances. Every preceding accepted event must qualify and agree;
uncertain preceding extrema disqualify the prefix. Small/cancelled tangents
are not labeled accurately resolved by this binary64 replay.

For every available pair, report full three-coordinate input and output
distances to **all four** depth-four references using [15,15,.01] and max norm.
Keep distances even when the regularity test fails. The conservative joint
distance is the maximum across both state endpoints, both solvers and all
four references; it is not a statistical uncertainty bound. A regular sampled
pair within 1e-6 is only a sampled-coverage witness, not a root certificate.
Report per-ordinal minima both with and without the regularity screen, retaining
ties and every underlying observation.

Adjacent nodes with same-ordinal, paired-regular endpoints, a common nonzero
input-x sign and opposite scalar slopes in both solvers are endpoint-only
candidate cells. Report input/output time jumps without declaring continuous
event identity across a cell. Zero slopes are retained but do not pass the
strict opposite-sign nomination. All unsampled interiors remain uncertified;
known grazing is a reason for direct sheet checks, not for connecting dots.

## Execution, validation and claim boundary

This analysis generates zero IVPs and spends zero API/GPU budget. Public input
hashes are provenance, not a repeat of their original local raw audit. Use a
standalone standard-library analyzer with analytic controls for correction,
cancellation, missing ordinals, uncertain prefixes, projection failures,
solver disagreement, full-state reference mismatch and strict sign changes.
Test the actual isolated CLI. Commit/push and live-verify the exact source
before its first complete target analysis. Keep a one-shot marker, fresh
output directory and source/input hashes. A repeat for public verification
is explicitly a deterministic saved-data replay, not another target attempt.
Cap the saved result at 16 MiB and the analysis process at 120 seconds.

The release must include the complete receipt, public replay, a figure showing
all direction/node/ordinal cells with invalid and missing cells distinguished,
and a dated plain-language account of what was and was not recovered. No new
root refinement, reference-guided recentering, external upload or paid review
is authorized by this protocol. A subsequent numerical test needs its own
prospective definition and must retain full-state, history/direction and
primitive-period checks.
