# EXP-504 local pre-target design audit

This is an outcome-informed successor to EXP-503, not an independent cold-start
replication. No paid review was requested. The local audit shares the scientific
solver helpers with the runner and does not claim independent-team certification.

The new controller changes seed transport and parameter selection, not the
frozen EXP-502 ODE/Decimal tolerances, branch census, fold qualification,
primitive-cycle qualification or full-state distance tests. Those sources remain
hash-bound through EXP-503. The new source closure includes the old public
receipt verifier, new model, runner, auditor, tests, protocol and machine plan.

The initial good-Broyden update uses only already published observations. Each
new point is uniquely fixed by its immediately preceding accepted point. All
256 correlated variants are retained; no alternate step, backtracking, favorable
representation, cyclic relabeling or best-earlier-point endpoint is permitted.
Both adjacent and original cycle identity are checked. Warm seeds preserve the
upstream affine initial curves. Model conditioning describes the secant model,
not a fresh measurement of the entire derivative.

Prospective controls cover separately coded scalar inverse/update identities,
known linear and clipped steps, nonlinear prediction rejection, singular and
wrong-orientation models, missing/reordered variants, invalid parameter domains,
authentic warm-seed transport, corrupted predecessor identities, first-failure
slot ledgers, immutable plan rejection and raw hash admission. An isolated
copied-source startup exercises the actual public inputs and full import closure.
Original analytic controls are hash checked and replayed, without target solves.

The full auditor checks the complete output inventory before interpreting it,
reconstructs every warm input and controller decision, and invokes the unchanged
full raw EXP-502 auditor for each completed point. Failed partial outputs remain
inventoried and cannot be treated as completed evidence. A subsequent compact
public replay must explicitly distinguish itself from this raw audit.

Resource admission requires 19 GiB free, preserves an 8 GiB floor, and limits
additional raw output to 10 GiB with a 64 MiB write margin. One exclusive marker,
3072 reserved IVPs and a 7200-second deadline bound the attempt. No reset of an
old marker, deletion, paid rental, model API, upload or dependency change occurs.

Validation results and exact pushed source identity belong in the dated update;
they must be observed before target execution, not asserted here in advance.
